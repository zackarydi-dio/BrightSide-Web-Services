# BrightSide Web Services

A responsive small business landing page built with HTML, CSS, and JavaScript. The site is designed for a fictional web services company and demonstrates core front-end development skills including layout design, CSS animations, and live DOM manipulation.

---

## 🌐 What It Does

BrightSide Web Services is a professional landing page for a small business that offers website design, SEO optimization, and e-commerce setup services. The page includes:

- A hero section with a dynamic, editable headline
- A services section with animated hover cards
- A live "Update Headline" feature powered by JavaScript
- A responsive layout that adapts to mobile screens
- Modern glassmorphism design with gradient backgrounds

---

## 🛠️ Technologies Used

- **HTML5** — Semantic page structure and accessibility
- **CSS3** — Flexbox layout, CSS Grid, hover transitions, media queries, and modern effects like backdrop-filter
- **JavaScript (Vanilla)** — DOM manipulation for live headline updates
- **Google Fonts** — Poppins font for modern typography

---

## 🚀 How to Run

No installation or dependencies required.

1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Use the "Update Headline" input at the bottom of the page to see the JavaScript feature in action
